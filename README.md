# Performance Appraisal App

Aplikasi sederhana berbasis HTML, CSS, dan JavaScript untuk menilai performance appraisal berdasarkan:
- Core Values (20%)
- Soft Competency (25%)
- Technical Competency (25%)
- KPI (30%)

## Fitur
- Hitung nilai total otomatis (0-100)
- Predikat hasil: Excellent / Good / Fair / Needs Improvement
- Simpan riwayat penilaian (maksimal 10 data) di localStorage
- Reset form penilaian

## Cara Menjalankan
Cukup buka file `index.html` di browser.
